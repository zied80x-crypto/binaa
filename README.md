# مقاول بناء — تطبيق إدارة المقاولة والعمال والرواتب

تطبيق Android (Kotlin + Jetpack Compose + Room) لإدارة مشاريع البناء، العمال، الحضور اليومي، التسبقات، ورواتب السبت. يعمل بدون إنترنت، بالعربية وبالكامل من اليمين لليسار، بالدينار التونسي.

## تثبيت التطبيق على الهاتف

1. افتح صفحة **Releases** في هذا المستودع (أو تبويب **Actions** ← آخر بناء ← `binaa-apk`).
2. نزّل ملف `binaa-XX.apk` على الهاتف.
3. افتح الملف. إن ظهر تحذير «مصادر غير معروفة» اضغط **الإعدادات** وفعّل «السماح من هذا المصدر»، ثم ارجع واضغط **تثبيت**.
4. التحديثات: نزّل النسخة الأحدث وثبّتها فوق القديمة — **البيانات تبقى** (كل النسخ موقّعة بنفس المفتاح). لا تحذف التطبيق قبل التحديث.

> قبل أي تحديث كبير: الإعدادات ← «نسخة الآن ومشاركتها» واحفظها في Drive أو واتساب.

## البناء من الكود

- كل `push` على الفرع `main` يشغّل GitHub Actions: اختبارات منطق الرواتب ثم بناء APK ونشره في Releases.
- محلياً: افتح المجلد في Android Studio (Ladybug أو أحدث، JDK 17) ثم Run، أو `./gradlew assembleRelease`.

## البنية

```
app/src/main/java/tn/binaa/app/
├── domain/      منطق نقي قابل للاختبار: المال (مليم)، أسبوع الدفع وقاعدة الأحد، حساب الراتب والتوقع
├── data/        Room: الكيانات، DAO، قاعدة البيانات، Repository (كل القواعد والتدقيق)
├── backup/      نسخ احتياطي تلقائي/يدوي واستعادة آمنة
├── reports/     8 تقارير + تصدير PDF و Excel (xlsx)
├── security/    رمز التصحيح للأسابيع المدفوعة
└── ui/          Compose: الرئيسية، الحضور، العمال، المشاريع، الرواتب، التقارير، الإعدادات
app/src/test/    اختبارات الحسابات وقاعدة الأحد
```

التفاصيل الكاملة (قاعدة البيانات، منطق الرواتب، مخاطر الحساب) في [`docs/DESIGN.md`](docs/DESIGN.md).

## ملاحظة عن مفتاح التوقيع

الملف `keystore/binaa.jks` موجود في المستودع (خاص) حتى تتمكن كل البنايات من تحديث التطبيق دون حذفه. لا تجعل المستودع عاماً. إن أردت نشر التطبيق في Play Store لاحقاً، أنشئ مفتاحاً جديداً واحفظه كـ GitHub Secret.
